# Operational Runbooks

This directory contains operational procedures, diagnostic guides, and release validation workflows for `blueshell` (`org.tunaos.blueshell`).

## Available Runbooks

- [Client & Terminal Diagnostics](client-diagnostics.md) - Diagnostic procedures for GTK, VTE, PTY spawn failures, and shell session crashes.
- [Flatpak Release & Validation](flatpak-release-and-validation.md) - Release build verification and Flatpak sandbox permission checks.
